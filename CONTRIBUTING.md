# Contributing

Read AGENTS.md and docs/INDEX.md. Develop on testing or a temporary branch, use Conventional Commits, keep changes bounded and document behavior. Run the checks appropriate to the affected modules. Never claim native/device success from web tests. Review docs/IDEAS.json before substantial work; unrelated ideas require selection. Preserve privacy projections, signing continuity, data and independent project identity.

Original contributions are AGPL-3.0-only. Include applicable notices; do not copy proprietary game art or branding. Keep security reports private. Do not make the repository or distribution endpoints public without the owner's authorization.
